Documentação da API

Referência completa da API do Portal Malb Imóveis: busca pública de imóveis, leads, o painel do corretor e a API de integração para CRMs parceiros (importação/exportação de imóveis e webhooks de leads e mudanças de status).

Para integrar um CRM parceiro, gere uma chave de API no painel em Parceiros (CRMs) e use-a no header X-Api-Key nas rotas /api/v1/parceiros/* abaixo.
